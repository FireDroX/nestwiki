# Security policy

## Supported versions

Security fixes are released for the latest `1.x` version only. Upgrade to the newest release before reporting a problem, and check the [changelog](CHANGELOG.md) in case it is already fixed.

| Version | Supported |
| --- | --- |
| Latest 1.x | ✅ |
| Older 1.x, 0.x | ❌ |

## Reporting a vulnerability

**Do not open a public issue, discussion or pull request for a security problem.**

Report it privately, by either:

- GitHub's private vulnerability reporting: the **Report a vulnerability** button in the [Security tab](https://github.com/FireDroX/nestwiki/security/advisories/new) of the repository (preferred);
- or an email to [contact@addrien.fr](mailto:contact@addrien.fr).

Please include the affected version, a description of the issue and its impact, and the steps or a minimal proof of concept needed to reproduce it. Do not access, modify or delete data that does not belong to you while investigating.

## What to expect

- An acknowledgement within 7 days.
- An assessment and, when the report is confirmed, a fix planned according to severity. You will be kept informed of the progress.
- A release containing the fix, with a changelog entry, before any public disclosure. You will be credited in the advisory unless you prefer otherwise.

NestWiki is maintained on a volunteer basis: these delays are goals, not contractual guarantees.
